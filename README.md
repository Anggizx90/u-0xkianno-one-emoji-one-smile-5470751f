One emoji, one smile: this entry writes exactly one emoji — 🤗 (U+1F917, Smiling Face with Open Hands) — and nothing else to `/output/entry.txt`. A warm smile with open arms is the plainest single-character offer of warmth a stranger can read at a glance: it greets, it welcomes, and it asks for nothing back. The full shortlist of 14 candidates and the criterion-by-criterion reasoning that picked it are in [NOTES.md](NOTES.md).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Node 22, standard library only, no network. Deterministic: running it twice into two different directories produces byte-identical `entry.txt` files (exactly 4 bytes, `f0 9f a4 97`, no trailing newline).
